## Когда использовать
Новый домен/модуль, который включается для школы или республики.

## Порядок
1. Изучи `backend/app/services/registry.py`, `backend/app/services/access.py`,
   `docs/04-data/02-model-grupp-prav-i-servisov.md`.
2. Добавь манифест сервиса: код, название, зависимости, права, роли по умолчанию.
3. Добавь права `{service}.read` и `{service}.programs.manage` (или конкретное
   право управления).
4. Добавь активацию сервиса для школы; по умолчанию — выключен.
5. Legacy-мост: сопоставь старые роли Flask с новыми правами.
6. Роутер `backend/app/api/v1/<service>.py`, подключи в `router.py`.
7. Тесты: доступ, 403 без активации, 403 без права, happy path.
8. Документация: API, модель данных, группы и права, журнал изменений.

## Запреты
- Не включать сервис по умолчанию без требования.
- Не давать права на уровне школы, если достаточно республиканского.
- Не забывать аудит доступа к ПДн.
