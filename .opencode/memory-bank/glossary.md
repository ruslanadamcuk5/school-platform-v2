# Glossary

- **ЕОРП «ВЕКТОР»** — Единая образовательная республиканская платформа.
- **Пилот** — `https://school-platform-v2.alwaysdata.net`; синтетические данные.
- **Сервис** — модуль платформы с манифестом, правами и активацией.
- **Активация** — включение сервиса для школы/республики.
- **Право** — `{service}.{action}`, проверяется через `require_permission`.
- **`school_id`** — граница мультитенантности; данные школы изолированы.
- **RLS** — Row-Level Security в PostgreSQL (план/частично).
- **Идемпотентность** — повторная операция не создаёт дубль.
- **`safety`** — сервис психологической поддержки, инцидентов, согласий и
  геолокации.
- **Согласие** — разрешение субъекта/законного представителя на обработку ПДн.
- **Retention** — срок хранения данных до очистки.
- **`synthetic_pilot_2026`** — метка синтетических пилотных данных.
