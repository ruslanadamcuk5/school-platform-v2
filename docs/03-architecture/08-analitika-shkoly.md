# Аналитика школы

| Параметр | Значение |
|---|---|
| Код документа | ШК-03-08 |
| Версия | 1.0 |
| Статус | Рабочий |
| Дата | 30.10.2026 |
| Связанные документы | ШК-03-03, ШК-03-04, ШК-03-05, ШК-03-07 |

## 1. Назначение

Сервис `analytics` формирует базовую управленческую отчётность школы:
численность участников, распределение оценок, посещаемость, срезы по
предметам и классам. Отчёт строится только по данным школы, к которой
пользователь имеет доступ.

## 2. Доступ

Сервис `analytics` включён по умолчанию и не является ядровым. Каждый запрос
проходит две проверки:

1. активация сервиса для области пользователя;
2. право `analytics.reports.read` или `analytics.bi.read`.

Выгрузка CSV дополнительно требует `analytics.reports.export`.

Параметр `school_id` обязателен для супер-администратора и игнорируется для
пользователя школы. Попытка обратиться к чужой школе возвращает `403`.

## 3. API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/v1/analytics/overview` | Сводный отчёт школы |
| `GET` | `/api/v1/analytics/export.csv` | Выгрузка классов в CSV |

Параметры:

- `school_id` — школа;
- `academic_year` — учебный год в формате `2026/2027`; если не задан,
  выбирается последний год, по которому в школе есть классы.

Ответ `overview` содержит:

- `totals` — ученики, учителя, классы, количество оценок;
- `grades` — средний балл, распределение 1–10 и группы качества;
- `attendance` — присутствие, отсутствие, болезнь, опоздание, уважительная
  причина и процент посещаемости;
- `subjects` — средний балл и посещаемость по предметам;
- `classes` — сводка по классам;
- `available_years` — список учебных годов школы.

Посещаемость рассчитывается как доля отметок `present` и `late` от всех
отметок журнала. Оценки без значения в поле `grade` в распределение не
попадают.

## 4. Изоляция и аудит

- Пользователь школы видит только свою школу.
- Супер-администратор выбирает школу явно.
- Выгрузка CSV фиксируется в аудите действием `analytics_report_exported`.
- В отчёте нет комментариев учителя, ответов учеников и иных лишних ПДн.
- Данные кешируются только в памяти браузера на время открытой страницы.

## 5. Веб-клиент

Маршрут `/analytics` доступен при наличии одного из прав
`analytics.reports.read` или `analytics.bi.read`. Экран показывает:

- карточки численности;
- распределение оценок по баллам и группам качества;
- кольцевую диаграмму посещаемости;
- рейтинг предметов по среднему баллу;
- таблицу классов;
- выбор учебного года;
- выгрузку CSV при наличии права.

## 6. Развитие

- отчёты по области, городу и стране через агрегаты;
- сравнение школ и динамика по периодам;
- отчёты по формам вышестоящих органов;
- конструктор BI-панелей;
- экспорт XLSX и PDF;
- кеширование агрегатов в Redis с инвалидацией по событиям журнала.
