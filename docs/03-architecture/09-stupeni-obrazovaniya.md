| Параметр | Значение |

## 1. Назначение

Платформа ЕОРП «ВЕКТОР» обслуживает не только школу, но все уровни
образования Республики Беларусь:

| Ступень | Код | Учреждения | Содержание |
|---|---|---|---|
| Начальное образование | `primary` | школы, гимназии | 1–4 классы, первые учителя, адаптация, родители |
| Среднее образование | `secondary` | школы, гимназии, лицеи | 5–11 классы, предметные профили, экзамены, профориентация |
| Среднее специальное образование | `vocational` | колледжи, техникумы | специальности, учебные группы, курсы, практика, зачётные книжки |
| Высшее образование | `higher` | университеты, академии, институты | программы, факультеты, кафедры, кредиты, академические группы, наука |

Каждая ступень реализована как **отдельный сервис** с собственным манифестом,
правами, API и переключателем активации. Республиканский администратор может
включить или отключить любую ступень для страны, области, города, учреждения
или группы. Начальное и среднее образование включены по умолчанию; среднее
специальное и высшее — выключены, пока республика не подключит
соответствующий контур.

## 2. Институциональная модель

### 2.1. Учреждение

`org.schools` хранит не только школы, но и учреждения профессионального и
высшего образования. Для этого добавлены поля:

| Поле | Назначение |
|---|---|
| `institution_type` | `school`, `college`, `university` |
| `education_levels` | JSONB-массив включённых ступеней учреждения |
| `profile` | JSONB-профиль учреждения: лицензии, аккредитации, реквизиты, контакты |

Правила соответствия:

| Тип учреждения | Допустимые ступени |
|---|---|
| `school` | `primary`, `secondary` |
| `college` | `vocational` |
| `university` | `higher` |

Учреждение создаётся и изменяется республиканским администратором через
`POST /api/v1/org/schools` и `PATCH /api/v1/org/schools/{id}`. Изменения
фиксируются в аудите.

### 2.2. Учебная группа

`org.classes` используется для классов школы и учебных групп колледжа/вуза:

| Поле | Назначение |
|---|---|
| `education_level` | ступень группы |
| `program_id` | образовательная программа (для профессиональных ступеней) |
| `course_year` | курс обучения |
| `profile` | JSONB-профиль: отделение, форма обучения, куратор, аудитория |

Для начальной и средней школы `program_id` и `course_year` не используются.
Для колледжа и вуза группа привязывается к программе и курсу.

### 2.3. Академические профили

Профессиональные ступени требуют дополнительных данных:

- `org.education_programs` — специальности и образовательные программы;
- `org.student_academic_profiles` — зачётная книжка, курс, группа,
  финансирование, академический статус;
- `org.staff_academic_profiles` — кафедра, должность, учёная степень,
  учёное звание.

Профили уникальны по пользователю. Пользователь должен принадлежать тому же
учреждению, что и профиль. Все изменения фиксируются в аудите.

## 3. Сервисы

| Код | Название | API | По умолчанию | Права |
|---|---|---|---|---|
| `primary_education` | Начальное образование | `/api/v1/education/primary` | включён | `primary_education.read`, `.manage` |
| `secondary_education` | Среднее образование | `/api/v1/education/secondary` | включён | `secondary_education.read`, `.manage` |
| `vocational_education` | Среднее специальное образование | `/api/v1/education/vocational` | выключен | `.read`, `.manage`, `.programs.manage`, `.profiles.read`, `.profiles.manage` |
| `higher_education` | Высшее образование | `/api/v1/education/higher` | выключен | `.read`, `.manage`, `.programs.manage`, `.profiles.read`, `.profiles.manage` |

Каждый запрос проходит две проверки:

1. сервис ступени включён для области пользователя (`require_service`);
2. у пользователя есть требуемое право (`require_permission`).

Учреждение также должно предоставлять запрошенную ступень в
`education_levels`; иначе возвращается `404`.

## 4. API ступени

Для каждой ступени доступен одинаковый контракт:

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/v1/education/{level}/overview` | Сводка: учреждение, группы, программы, профили |
| `GET` | `/api/v1/education/{level}/groups` | Учебные группы и классы ступени |
| `GET` | `/api/v1/education/{level}/programs` | Образовательные программы |
| `POST` | `/api/v1/education/{level}/programs` | Создать программу (профессиональные ступени) |
| `PATCH` | `/api/v1/education/{level}/programs/{id}` | Изменить программу |
| `GET` | `/api/v1/education/{level}/profiles` | Академические профили обучающихся |
| `POST` | `/api/v1/education/{level}/profiles` | Создать профиль обучающегося |
| `PATCH` | `/api/v1/education/{level}/profiles/{id}` | Изменить профиль обучающегося |
| `GET` | `/api/v1/education/{level}/staff-profiles` | Профили преподавателей |
| `POST` | `/api/v1/education/{level}/staff-profiles` | Создать профиль преподавателя |
| `PATCH` | `/api/v1/education/{level}/staff-profiles/{id}` | Изменить профиль преподавателя |

Общие правила:

- `school_id` обязателен для республиканского администратора; для пользователя
  учреждения берётся из токена;
- попытка открыть чужое учреждение возвращает `403`;
- группа, программа и профиль должны принадлежать учреждению и ступени;
- список учебных годов строится по группам ступени;
- программы и профили доступны только для `vocational` и `higher`;
  для школьных ступеней возвращается пустой список;
- создание и изменение программ/профилей фиксируется в аудите.

## 5. Управление учреждениями

| Метод | Путь | Право | Назначение |
|---|---|---|---|
| `GET` | `/api/v1/org/schools` | авторизация | Список доступных учреждений |
| `POST` | `/api/v1/org/schools` | `org.schools.write` | Создать учреждение (только республиканский администратор) |
| `PATCH` | `/api/v1/org/schools/{id}` | `org.schools.write` | Изменить учреждение (только республиканский администратор) |
| `GET` | `/api/v1/org/classes?education_level=` | авторизация | Классы и группы, в том числе по ступени |

## 6. Веб-клиент

| Маршрут | Ступень | Доступ |
|---|---|---|
| `/education/primary` | Начальное образование | `primary_education.read` |
| `/education/secondary` | Среднее образование | `secondary_education.read` |
| `/education/vocational` | Среднее специальное образование | `vocational_education.read` |
| `/education/higher` | Высшее образование | `higher_education.read` |

Экран ступени показывает:

- выбор учреждения для республиканского администратора;
- учебный год;
- численность обучающихся, преподавателей, групп и программ;
- таблицу групп с кураторами;
- список программ и управление ими при наличии права;
- академические профили для профессиональных ступеней;
- создание учреждения выбранного типа для республиканского администратора.

## 7. Обучение работе в платформе

В каталог `onboarding` добавлены четыре модуля: `primary-education`,
`secondary-education`, `vocational-education`, `higher-education`. Они
появляются у пользователя только при включённой ступени и наличии прав.
Для профессиональных ступеней дополнительно требуется право просмотра
профилей. При включении новой ступени модуль появляется как «дообучение».

Версия каталога обучения — `1.1.0`, всего 19 модулей в 5 этапах.

## 8. Миграция и данные

Миграция `0004_education_levels`:

- добавляет `institution_type`, `education_levels`, `profile` в `org.schools`;
- добавляет `education_level`, `program_id`, `course_year`, `profile` в
  `org.classes`;
- создаёт `org.education_programs`, `org.student_academic_profiles`,
  `org.staff_academic_profiles`;
- проставляет классам 1–4 ступень `primary`, остальным — `secondary`.

Seed создаёт 4 сервиса, 14 прав и 4 активации. Пилотная школа получает
ступени `primary` и `secondary`. Для профессиональных ступеней учреждение
создаётся через API или интерфейс республиканского администратора.

## 9. Безопасность

- Профили студентов и преподавателей содержат ПДн и доступны только по
  правам `.profiles.read` / `.profiles.manage`.
- Изменения программ, профилей и учреждений аудируются.
- Отчёты и списки не содержат лишних ПДн: только ФИО, логин, программа,
  группа, курс и академический статус.
- Отключение ступени немедленно закрывает её API для области, даже если
  права остались у группы.

## 10. Ограничения и развитие

- Нет отдельного справочника факультетов и кафедр; кафедра хранится строкой
  в профиле преподавателя.
- Нет учебных планов, кредитов и зачётных ведомостей; следующий шаг —
  модуль `higher_education` с кредитами и сессиями.
- Нет производственной практики и договоров с предприятиями; следующий шаг —
  модуль `vocational_education` с практикой и компетенциями.
- Массовый импорт контингента и приказов требует отдельного согласования.
