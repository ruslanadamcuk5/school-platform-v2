## Обозначения приоритетов
- **P0** — обязательно для первого промышленного релиза.
- **P1** — обязательно для республиканского уровня, следующий этап.
- **P2** — развитие, после пилота.
- **Есть** — функция уже реализована в текущей системе.
- **Перенос** — функция есть, но должна быть перенесена.
- **Новое** — требуется разработать.

## 10. Критерии приёмки функций
1. Функция доступна во всех заявленных клиентах.
2. Права доступа проверены для всех ролей.
3. Есть автотесты или документированный сценарий проверки.
4. Ошибки обрабатываются и не раскрывают внутренние данные.
5. Данные сохраняются при потере связи.
6. Действие фиксируется в аудите, если оно значимое.
7. Интерфейс доступен на RU/BY/EN (для пользовательских функций).
8. Функция описана в пользовательской документации.
