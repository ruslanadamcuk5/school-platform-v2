## 4. Найденные дефекты и исправления

1. **500 при открытии карточки группы.** Причина: ленивая загрузка
   `memberships` и `permission_links` у дочерних групп в async SQLAlchemy.
   Исправление: добавлены `selectinload` для дочерних связей; добавлен тест на
   счётчики дочерних групп.
2. **CORS при запросе `/health`.** Причина: клиент обращался напрямую к
   `127.0.0.1:8000` в обход Vite-прокси. Исправление: относительный `/health` в
   разработке и origin из `VITE_API_URL` при явном внешнем API.
3. **Конфликт Tailwind-классов.** Причина: `bg-white` из базового `Card`
   перекрывал `bg-slate-950` у hero-блока. Исправление: `cn` переведён на
   `tailwind-merge`.
4. **Плавающий бейдж версии перекрывал таблицу.** Исправление: декоративный
   бейдж удалён, версия осталась в боковом меню.

## 5. Ограничения

- Автоматизированные E2E-тесты и визуальные regression-тесты не подключены.
- Пилотная школа пока не содержит пользователей, кроме супер-администратора;
  поэтому сводка по ролям пустая.
- Проверка проводилась на локальном backend и Vite; пилотный домен проверяется
  после деплоя.
