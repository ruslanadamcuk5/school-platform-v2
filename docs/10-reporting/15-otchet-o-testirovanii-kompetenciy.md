| Код документа | ШК-10-15 |

| Статус | Рабочий |
| Дата | 04.11.2026 |

| Связанные документы | ШК-03-03, ШК-03-06, ШК-03-09, ШК-10-04 |

## 1. Объект испытаний

- миграция `0007_competencies`;
- таблицы `org.competencies`, `org.program_competencies`,
  `org.component_competencies`;
- API каталога компетенций, матрицы программы и матрицы учебного плана;
- веб-блок «Компетенции и матрица» на экране `/education/{level}`;
- синтетические компетенции и связи в пилотном seed.

## 2. Проверенные сценарии

| № | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Миграция `0007` | Созданы три таблицы, индексы, ограничения и внешние ключи | Успешно |
| 2 | Тип компетенции | Допустимы `universal`, `general`, `professional`, `other` | Успешно |
| 3 | Целевой уровень | Значения вне диапазона 1–5 отклоняются | Успешно |
| 4 | Вес компетенции | Значения вне диапазона 0–100 отклоняются | Успешно |
| 5 | Уникальность кода | Повтор кода в учреждении отклоняется | Успешно |
| 6 | Принадлежность компетенции | Чужая компетенция или другая ступень отклоняются | Успешно |
| 7 | Матрица программы | Повтор компетенции в запросе отклоняется | Успешно |
| 8 | Замена матрицы программы | Старые связи удаляются, новые сохраняются | Успешно |
| 9 | Матрица плана | Принимаются только компоненты этого плана | Успешно |
| 10 | Матрица плана | Принимаются только компетенции этого учреждения и ступени | Успешно |
| 11 | Дубли связей | Повтор пары «компонент + компетенция» отклоняется | Успешно |
| 12 | Чтение | Каталог и матрицы доступны по `{service}.read` | Успешно |
| 13 | Управление | Создание и изменение требуют `{service}.programs.manage` | Успешно |
| 14 | Аудит | Создание, изменение и замена матриц фиксируются в аудите | Успешно |
| 15 | OpenAPI | Маршруты компетенций есть только у профессиональных ступеней | Успешно |

| 18 | Пилотный seed | Повторный запуск не создаёт дубликатов компетенций и связей | Успешно |

## 3. Автоматические проверки

```text
backend: 138 passed
ruff: all checks passed
frontend: npm run typecheck — успешно
frontend: npm run build — успешно
alembic offline SQL: 0007_competencies — успешно
```

Новые и расширенные тесты:

- `tests/test_education_levels.py` — валидация компетенций, целевых уровней,
  весов и матрицы, проверка маршрутов в OpenAPI;
- `tests/test_openapi.py` — отсутствие профессиональных маршрутов у школьных
  ступеней;
- `tests/test_pilot_data.py` — импорт и базовые инварианты пилотного seed.

## 4. Ограничения проверки

1. Миграция `0007_competencies` проверена генерацией offline SQL, но не
   применялась к пилотной PostgreSQL до отдельной команды.
2. Обновлённый пилотный seed не запускался на пилоте; синтетические
   компетенции и матрицы появятся после миграции и повторного seed.
3. Живые HTTP-проверки новых маршрутов на пилоте не выполнялись, потому что
   код и схема БД ещё не доставлены.
4. Оценка сформированности компетенции у конкретного обучающегося и связь
   компетенций с результатами ведомостей запланированы на следующий этап.

## 5. Вывод

Каталог компетенций, целевые уровни программ и матрица учебного плана
реализованы и проверены на уровне схемы, API, UI-сборки и автоматических
тестов. Доставка миграции и данных на пилот выполняется только после
отдельного распоряжения.
