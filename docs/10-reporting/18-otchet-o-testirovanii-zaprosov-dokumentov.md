| Параметр | Значение |
|---|---|
| Код документа | ШК-10-18 |
| Версия | 1.0 |
| Статус | Рабочий |
| Дата | 04.11.2026 |
| Проект | ЕОРП «ВЕКТОР» |
| Связанные документы | ШК-03-03, ШК-03-06, ШК-04-01, ШК-10-04 |

## 1. Объект испытаний

- миграция `0009_document_requests`;
- таблица `documents.document_requests`;
- API `/api/v1/documents/requests` для справок и заявлений;
- права `documents.requests.create` и `documents.requests.process`;
- проверки активации сервиса `documents`;
- типы и клиент запросов документов веб-приложения;
- аудит создания, обработки и отмены заявки.

  отсутствии права создания.

## 4. Ограничения проверки

1. Испытания не подключались к реальной PostgreSQL: проверялись схема,
   offline SQL, зависимости FastAPI, каталог прав и OpenAPI.
2. Заявки не добавлены в пилотный seed; после доставки кода список будет
   пустым до создания первой заявки.
3. Сервис `documents` по умолчанию отключён и должен быть включён
   республиканским администратором для школы.
4. Электронная подпись, шаблоны и печатные формы документов не реализованы.
5. Живые HTTP-проверки на пилоте не выполнялись, потому что код и миграция
   ещё не доставлены.

## 5. Вывод

Запросы документов реализованы как защищённый срез сервиса `documents`:
активация, права, схема, обработка, отмена, аудит и OpenAPI проверены.
Миграция `0009_document_requests` подготовлена, но к пилоту не применялась.
