## 3. Статусы
- **Черновик** — документ создан, требует согласования.
- **На согласовании** — передан заинтересованным сторонам.
- **Утверждён** — подписан владельцем/заказчиком.
- **Изменён** — есть утверждённая новая версия.
- **Архив** — заменён, хранится для истории.

## 4. Правила версионирования
- 0.x — черновые версии до утверждения.
- 1.x — утверждённая версия; минорные изменения.
- 2.x — существенная переработка, требующая повторного согласования.

## 5. Хранение
Исходные документы — в Git-репозитории проекта. Официальные DOCX-версии —
в папке `docs/word/`. Резервные копии — не реже одного раза в месяц и перед
каждой сдачей этапа.
